# show-gi — 개발 문서

AI가 사람의 행동에 개입할 타이밍과 강도를 스스로 조절하는 제품. 검증 도메인은 쇼기(将棋).

초심자가 큰 실수를 두는 순간에만 개입해 이유를 설명하고 되무른다. 평소에는 최선수를 보여주지 않는다. 指導対局처럼 사람이 둔 수에 따라 상대 AI의 강함을 대국 중에 조절한다.

> 실력 추정에 따른 조절은 동작하지만, 난이도가 사람에게 충분히 맞춰진다고 단정할 수는 없다. 실측에서 양보 폭은 +63cp 늘었고 밴드 폭은 200cp다([§17](journal/06-20.md) · [§47](journal/41-60.md)).

> 제품 소개는 [레포 루트 README](../README.md)에 있다. 이 문서는 내부 개발 문서의 목차다.

## 원칙 두 가지

- 제품의 코어는 개입 루프다. 대국·리뷰·3D는 전부 그것을 보여주기 위한 장치다.
- **판단도 표현도 결정적이다.** 학습 앱에서 설명이 틀리면 초심자는 검증할 수 없다.

## 스택

React + TypeScript + Vite (three.js) / Go (USI 엔진 브리지) / PostgreSQL / AWS + Terraform

확인하지 못한 항목은 추정으로 메우지 않고 `[미확정]`으로 표시한다.

> 04와 07은 삭제한 LLM 계층 문서와 Zenn 기사 문서의 번호다. 코드 주석의 참조를 유지하기 위해 번호를 다시 매기지 않는다.
