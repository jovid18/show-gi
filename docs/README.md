# show-gi — 개발 문서

**AI가 사람의 행동에 개입할 타이밍과 강도를 스스로 조절하는 제품.** 검증 도메인은 쇼기(将棋).

초심자가 큰 실수를 두는 순간에만 개입해 이유를 설명하고 되무른다. 평소엔 최선수를 보여주지 않고, 상대 AI의 강함은 사람이 둔 수를 보고 한 판 안에서 움직인다 — 스승의 지도 대국(指導対局)처럼.

> **「난이도가 사람에 맞춰 변한다」로는 아직 못 쓴다.** 너그러운 쪽으로 실제로 옮겨간 폭이 **+63cp**이고 밴드 폭이 200cp다. 참인 것은 「조절이 사람을 보기 시작했다」까지다 ([06-status §17](06-status.md) · [§47](06-status.md)).

## 원칙 두 가지

- 제품의 코어는 **개입 루프**다. 대국·리뷰·3D는 전부 그것을 보여주기 위한 장치다.
- **판단은 엔진, 표현만 LLM.** 학습 앱에서 설명이 틀리면 초심자는 검증할 수 없다.

## 스택

React + TypeScript + Vite (three.js) / Go (USI 엔진 브리지) / PostgreSQL + pgvector / OrcaRouter / AWS + Terraform

확인하지 못한 항목은 추정으로 메우지 않고 `[미확정]`으로 표시한다.
