# 제품 — 문제 · 시장 · 프레이밍

## 1. 한 줄 정의

> **AI가 사람의 행동에 개입할 타이밍과 강도를 스스로 조절하는 제품.** 검증 도메인은 쇼기(将棋).

여기서 파생되는 제약 두 가지가 이 프로젝트의 거의 모든 결정을 지배한다.

- 제품의 코어는 **개입 루프**다. 대국 기능·리뷰 화면·3D는 전부 그 루프를 보여주기 위한 장치다.
- **판단은 엔진, 표현만 LLM.** 학습 앱에서 설명이 틀리면 초심자는 검증할 능력이 없어 틀린 것을 그대로 배운다. LLM이 "이 수가 나쁘다"를 정하는 경로는 만들지 않는다.

### 프레이밍 원칙

| 하지 말 것                    | 할 것                                                   |
| ----------------------------- | ------------------------------------------------------- |
| "쇼기 학습 앱을 만들었습니다" | "개입 타이밍 제어 제품입니다. 검증 도메인이 쇼기입니다" |
| 제목에 "쇼기" 넣기            | 제목은 개입 문제로. 쇼기는 2번째 슬라이드에서 등장      |

### 왜 쇼기인가

한국에는 쇼기 문화가 거의 없다. 일본에 오면서 시작했고, 재미있는데 학습 곡선이 가파르다. **사용자의 시행착오를 통해 배우도록 도와주는 것**이 개인적 출발점이고, 동시에 "정답이 객관적으로 존재하는 학습 영역"이라 개입 판정을 엔진으로 검증할 수 있다.

## 2. 해결하려는 문제

[aihackathon.jp](https://aihackathon.jp/)

기존 쇼기 학습 환경의 공백:

- 쇼기는 쉬운 게임이 아니고, 일본에서 시장은 꽤 크다.
- **사람 대 사람**은 오프라인이면 시간·금전 비용이 크고, 온라인 PvP는 대부분 시간 제한이 있어 느긋하게 연습하기 어렵다.
- **컴퓨터 대전**은 양극단이다. 쉬운 난이도는 말도 안 되는 곳에 말을 던져 자멸하고, 어려운 난이도는 사용자의 작은 실수 하나에 국면이 통째로 뒤집힌다.
- → **실제로 스승이 지도 대국(指導対局)을 두듯, 사람의 수준에 맞춰 컴퓨터의 수준이 실시간으로 변하면 어떨까?** 이것이 프로젝트의 핵심 목표다.

## 4. 시장 조사

### 결론: 쇼기에는 이 조합이 없다

기능을 쪼개면 각 조각은 존재한다. **"둘 때 개입"** 부분만 비어 있다.

| 요구사항                         | 현존 여부 | 비고                               |
| -------------------------------- | --------- | ---------------------------------- |
| ① 수준 측정                      | ○         | ぴよ将棋 레이팅, 将棋ウォーズ 단급 |
| ② 평소엔 힌트 없음               | ○         | 기본값                             |
| ③ **블런더 시 개입 + 이유 설명** | ✗         | **없음**                           |
| ④ 다시 두기                      | △         | 「待った」는 사용자가 수동으로     |
| ⑤ 약점 프로파일링                | △         | 사후 분석만                        |

### 경쟁 / 참고 서비스

- **ぴよ将棋** (무료, iOS/Android/Web) — 40단계 AI. 리얼타임 힌트(비레이팅 대국 한정), 3택 모드, 대국 후 검토 + 기보 해석(악수 자동 검출, 평가치 그래프). **기능 최강 / UI 낙후.**
- **将棋ウォーズ** (HEROZ) — 누적 800만 유저, 통산 10억 국. 棋神解析, 棋神降臨.
- **棋神ラーニング** (ウォーズ 내, 월 1,200엔) — 동영상+퀴즈, 개인 강약점 개인화, **자기 대국에서 "다음 한 수" 문제 출제**. ⑤에 가장 가까우나 전부 사후.
- **棋神アナリティクス** (Web) — dlshogi with HEROZ / 水匠7. 스탠다드 월 11,000엔(10시간, 이후 1분 20엔), 라이트 월 1,100엔.
- **きふみAI** — 악수 자동 검출 + 승률 상승 5국면 명시. **棋風 레포트 10축 분석**(전형·囲い별 승률, 기간별 추이). ⑤의 사후판.
- **lishogi.org** — 무료 오픈소스. やねうら王 기반 해석, 실전 자동 추출 "다음 한 수" 문제. **대국 중 소프트 참조 금지 명시** ([보안](02-architecture.md#7-보안--도메인-고유의-실재-위협) 참조).
- **ShogiHome / ShogiGUI / 将棋所** (PC, 무료) — USI 엔진 프론트엔드. 실시간 검토는 가능하나 설치 허들.

### 기준 4 — AI である必然性 (2층 방어)

- **판정층:** 엔진 필수. 룰로는 블런더 판정이 불가능하다 (자명).
- **표현·개입층:** "설명 문장 생성"이라고 말하면 약하다. **개인화**로 말해야 한다.
  > 같은 블런더라도 10급과 초단에게 해야 할 말이 다릅니다. 개입 임계치도, 설명 깊이도, 어떤 개념을 이미 안다고 가정할지도 다릅니다. **사용자 모델에 조건부인 설명**은 템플릿으로 안 됩니다.
- 그 개인화의 입력이 ⑤ 약점 프로파일 → **4·5·8이 한 줄로 연결된다.**

### 기준 2 — ビジネス成立性

시장 축소는 인정한다. 대신 **지불 의사는 이미 증명되어 있다.**

- 将棋ウォーズ 누적 800만 유저 / 10억 국
- 棋神ラーニング 월 1,200엔, 棋神アナリティクス 라이트 월 1,100엔이 실제로 팔린다
- → 이 도메인 유저는 학습에 **월 1,000엔대를 이미 지불 중.** 신규 시장 개척이 아니라 기존 지불 시장에 더 나은 제품으로 진입하는 것.

확장 서사:

> 쇼기는 첫 시장입니다. 개입 엔진 자체는 도메인 독립적이고, **정답이 객관적으로 존재하는 학습 영역**이면 어디든 적용됩니다.
