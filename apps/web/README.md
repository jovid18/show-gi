# apps/web

클라이언트. 판을 그리고, 개입 순간을 연출하고, 복기 화면에서 분기를 보여준다. 설계는 [docs/03-frontend.md](../../docs/03-frontend.md).

## 실행

서버와 클라이언트를 각각 띄운다.

```sh
docker compose up -d      # api + db. 레포 루트에서
pnpm dev                  # :5173. 레포 루트에서
```

**api는 컨테이너로 띄운다.** `go run ./cmd/api` 도 서버는 뜨지만 **대국이 안 된다** — 엔진이 arm64 Debian 바이너리라 macOS에서 직접 안 돌고, `/healthz` 가 `engine:false` 를 준다.

개발 서버는 `/healthz` · `/api` · `/ws`를 `http://localhost:8080`으로 프록시한다. 서버를 다른 포트로 띄웠다면 `SERVER_ORIGIN=http://127.0.0.1:9000 pnpm dev`.

프록시를 두는 이유는 클라이언트가 개발·배포에서 똑같은 상대 경로를 쓰게 하려는 것이다. `ws://localhost:8080/ws` 같은 절대 주소를 코드에 적으면 배포 때 갈라진다.

> `localhost:8080`에 다른 것이 이미 떠 있으면 프록시가 그쪽으로 간다. 특히 Node가 `localhost`를 IPv6(`::1`)로 먼저 풀기 때문에, IPv4에만 바인딩한 서버는 조용히 지나친다. 그럴 때는 `SERVER_ORIGIN`에 `127.0.0.1`을 명시할 것.

## 언어

**화면에 나가는 문자열은 전부 일본어다.** 사용자는 일본인이다. 주석과 이 문서는 한글이지만, JSX 안의 텍스트·에러 메시지·빈 상태 문구에 한글이 섞이면 안 된다.

`index.html`의 `lang="ja"`와 `index.css`의 폰트 스택(Hiragino / Noto Sans JP)이 그 전제 위에 있다.

## 배치

전부 `src/app/` 아래다. **가로축이 화면, 세로축이 층**이라고 읽으면 된다.

|                   |                                                                                                                   |
| ----------------- | ----------------------------------------------------------------------------------------------------------------- |
| `screens/home`    | 첫 화면. 갈 수 있는 곳을 세로로 세운 메뉴 하나뿐이다([journal §86](../../docs/journal/82-100.md))                 |
| `screens/game`    | 대국 화면 — 판·개입 카드·기보·총평·手合割/선후공 선택·이어하기                                                    |
| `screens/review`  | 되짚기 — 평가치 궤적 그래프(`EvalGraph`)·수 목록·가정 수순 패널                                                   |
| `screens/quiz`    | 되짚기 퀴즈. `/reviews/:id/quiz`                                                                                  |
| `screens/explore` | 검토. 手合割을 골라 0手目부터 놓아 보는 판. **두는 중에는 안 열린다**                                             |
| `screens/match`   | 사람끼리 두는 판. 초대 링크로 들어온다 — 개입도 힌트도 待った도 없다                                              |
| `screens/me`      | 마이페이지. 段級·전적·崩れやすいところ·組んだ形                                                                   |
| `screens/guide`   | 안내(`あそびかた`). **서버에 아무것도 안 묻는 유일한 화면이다** — 글과 見本뿐이다                                 |
| `components`      | 화면을 가로지르는 것만 — 판(`Board`)·駒(`Koma`)·駒台(`Hand`)·로그인(`Account`)                                    |
| `hooks`           | 서버와 말하는 자리. `useGame` 이 WebSocket 하나를 들고, 나머지는 REST                                             |
| `protocol`        | **서버 응답의 타입만.** 로직을 두지 않는다 — 여기가 두꺼워지면 규칙이 두 벌이 된다                                |
| `models`          | 순수 함수. 좌표(`square`)·SFEN·駒·利き(`influence`)·이동 범위(`mobility`)                                         |
| `libs/three`      | 판 표면 한 겹(`surface.ts`). **정사영 카메라이고 駒·광선·표식은 그대로 DOM이다**                                  |
| `libs/whatif`     | 가정 수순의 분기를 화면이 들고 있는 자리. **서버에 저장하지 않는다**([03-frontend §3](../../docs/03-frontend.md)) |
| `libs/sound`      | 착수음을 그 자리에서 만든다 — 파일이 없다([journal §70](../../docs/journal/61-81.md))                             |
| `routes`          | 경로 문자열과 파서. **`const.ts` 만 주소를 안다**                                                                 |

`@`는 `src/app`이다. 별칭은 `tsconfig.json`과 `vite.config.ts` 두 곳에 적혀 있으니 한쪽만 고치지 말 것.

`src/` 밖에 둘이 더 있다. **번들에 안 들어가는 것들이다.**

|           |                                                                                                                              |
| --------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `brand/`  | 로고 원본(`logo.png`)과 아이콘 생성 스크립트(`icons.sh`). **빌드가 안 돌린다** — 사람이 로고를 갈아 끼울 때 한 번 돌린다     |
| `public/` | 그 결과물 + `robots.txt` · `sitemap.xml` · `site.webmanifest`. Vite가 손대지 않고 `dist/` 로 그대로 옮긴다 (주소가 고정이다) |

**클라이언트는 규칙을 하나도 모른다.** 二歩도 打ち歩詰め도 모르고, 서버가 준 `legalMoves` 만 믿는다. 스냅샷도 **언제나 전체**라 부분 갱신이 없다 — 롤백 뒤에 화면과 서버가 어긋나면 알 방법이 없기 때문이다.

## 좌표

쇼기는 두 축의 이름과 방향이 다르다. **筋(file)은 오른쪽부터 1\~9**, 段(rank)은 위부터 1\~9다. 화면 배열은 사람이 판을 보는 순서대로 왼쪽 위(9筋 1段)부터 행 우선으로 깐다.

그래서 `index = (rank-1)*9 + (9-file)`이고, `9-file`이 이 도메인에서 가장 자주 틀리는 지점이다. `square.test.ts`가 81칸을 전부 왕복 검사하는 이유가 그것이다.

사람이 읽는 표기(「7六」)와 엔진이 쓰는 USI 표기(`7f`)가 다르다는 것도 주의. 段만 a\~i로 바뀐다.

## 주소

문자열은 `routes/const.ts` 하나만 안다.

| 주소                  | 무엇                                                                                                  |
| --------------------- | ----------------------------------------------------------------------------------------------------- |
| `/`                   | 홈. 메뉴 한 벌이 전부이고 서버에 아무것도 안 묻는다([journal §86](../../docs/journal/82-100.md))      |
| `/play`               | 대국. 手合割·선후공·상대의 진형을 고르고 시작한다. 중단된 판이 있으면 먼저 물어본다                   |
| `/reviews`            | 되짚기 목록. **결과가 나온 판만** 나간다 (§51)                                                        |
| `/reviews/:id[/:ply]` | 한 판 되짚기. 手数가 주소에 있는 이유는 총평의 링크가 새로고침에 안 사라지게 하려는 것이다            |
| `/reviews/:id/quiz`   | 그 판에서 뽑은 퀴즈. 문항이 0개인 판이 흔하다                                                         |
| `/explore`            | 검토. 手合割과 수순이 쿼리에 실린다(`?h=…&m=…`) — 링크와 새로고침이 그것으로 산다                     |
| `/rooms/:id`          | 사람끼리 두는 방. id가 곧 열쇠라 연번이 아니다(영숫자 8자)                                            |
| `/me`                 | 마이페이지. **로그인한 사람만**이고 익명은 401이다                                                    |
| `/guide`              | 안내. 로그인도 서버도 안 본다. **입구는 홈 메뉴 하나다**([journal §86](../../docs/journal/82-100.md)) |

**대국 화면은 라우트 밖에 상시 마운트다.** WebSocket 하나에 매여 있어 언마운트하면 그 판이 `abandoned` 로 닫힌다 — 그래서 라우터가 element 를 갈아 끼우지 않고 감추기만 한다(`App.tsx` · `routes/router.ts`). 두는 중에는 다른 주소가 판으로 되돌아온다.

## 아직 없는 것

- **three.js는 1.5컷이다** ([journal §35](../../docs/journal/21-40.md) · [§41](../../docs/journal/41-60.md)). 판 표면과 利きの그늘은 들어왔고, **컷 2**(회상에서 한 칸에 고이는 그늘)는 **자동으로 안 켜진다** — 탈색된 판에서 판에 낀 흠으로 읽혀 토글로만 남겼다. WebGL이 없으면 CSS 판 그대로다
- **다크모드가 없다** ([§50](../../docs/journal/41-60.md)). `color-scheme: light` 하나이고 `prefers-color-scheme` 을 안 본다. 어두운 것은 화면이 아니라 **판이 있는 방**이고, 그 방은 개입이 걸릴 때 `.veil` 이 만든다
- **제안형 힌트의 영역 표시가 없다.** 이름은 뜨지만 「어느 쪽인가」를 판 위에 그리는 쪽은 아직 없다 ([01-core.md §7](../../docs/01-core.md))
